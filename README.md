# deep-autoencoders-2006-from-scratch-in-numpy
Reducing the Dimensionality of Data with Neural Networks (Hinton and Salakhutdinov, 2006), rebuilt in NumPy with every gradient written by hand. A deep autoencoder squeezes each 784-pixel MNIST digit through a small layer of 30 numbers and rebuilds the image from them.
